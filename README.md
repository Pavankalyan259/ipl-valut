# 🏏 IPL Vault

IPL Vault is a frontend IPL information website built using HTML, CSS, and JavaScript.

## Features

- IPL team directory
- 18–25 players listed for each team
- Team IPL entry year
- IPL title history
- Team captain
- Home stadium
- Team sponsor
- Player profiles
- Player country
- Date of birth
- IPL debut
- Team joining year
- IPL career statistics
- Career runs and wickets
- Centuries and half-centuries
- Five-wicket hauls
- Double centuries
- Team search
- Frontend sign-in/register demonstration
- Responsive design
- GitHub Pages ready

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- GitHub Pages

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html`.
4. Right-click `index.html`.
5. Select **Open with Live Server**.

## Authentication

The project contains a simple frontend-only sign-in/register demonstration.

It uses browser `localStorage`. It does not provide real Google OAuth, SMS OTP verification, or production-level authentication.

## Player Statistics

Player statistics are presented as IPL career information. Statistics should be interpreted according to the data period shown on the player profile.

## Project Type

This is a frontend-only educational project. No backend or database is required.

## Deployment

The project can be hosted using GitHub Pages.
